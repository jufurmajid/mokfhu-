# Milestone 1 — Player + Weapon + Mobile Controls

This is a clean restart of the Android FPS project.

## What exists

- First-person player controller
- 82° camera at 1.55 m eye height
- Animated AK-74M + hands viewmodel
- Idle, walk, shot and reload animations
- Left virtual joystick
- Right-side drag camera control
- Fire and reload buttons
- Ammo display and crosshair
- Large 140 x 140 m test floor
- Procedural sand shading, desert sky, sun and subtle fog
- Landscape Android layout

## What does NOT exist yet

- enemies
- enemy AI
- enemy projectiles
- missions
- buildings
- rocks
- cover props
- win/death states

Those will only be added later, one step at a time after this base is visually accepted on the phone.

## Desktop test controls

- WASD / arrow keys: movement
- Mouse: look
- Left click: fire
- R: reload
